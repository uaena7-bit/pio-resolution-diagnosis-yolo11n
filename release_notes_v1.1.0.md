# v1.1.0 - Precision Agriculture submission materials

This release updates the reproducibility repository for the Precision Agriculture submission.

- Updated the repository description from the previous CSSP-oriented submission version to the Precision Agriculture submission version.
- Added the final manuscript Fig. 1 workflow diagram and its Python generation script.
- Added the updated Fig. 5 qualitative resolution-comparison figure.
